# Daily Quote

Daily Quote är en enkel webbsida byggd med Vue som ramverk och TypeScript.

Sidan visar dagens datum, tiden just nu och ett dagligt citat. Man kan även klicka på en knapp för att slumpa fram ett nytt citat.

## Tekniker

- Vue
- TypeScript
- Vite
- HTML
- CSS

## Vue-funktioner

I projektet används följande delar av Vue:

- Databindning
- Villkorlig rendering
- Tillståndshantering
- Eventhantering
- Komponenter

## Installation

Installera projektets paket med:

npm install

## Starta projektet

Starta utvecklingsservern med:

npm run dev

Öppna sedan adressen som visas i terminalen.

## Bygga projektet

Projektet kan byggas med:

npm run build
